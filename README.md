# Personal Analytics & Habit Tracker

A modern, fully responsive **Single Page Application (SPA)** built using **Next.js, Tailwind CSS, and TypeScript**. This app helps users set and monitor daily habit goals like sleep and water intake, visualize progress trends, and build consistent routines.

---

##  Features

- **Daily Goal Setting** – Adjust sleep and water intake goals using interactive sliders
- **Progress Visualization** – View weekly trends using smooth, responsive charts (`recharts`)
- **Motivation Tracking** – Monitor consistency and performance trends
-  **Beautiful UI** – Glassmorphism cards, gradient backgrounds, and responsive design
-  **Smooth Animations** – Page and component animations powered by `framer-motion`

---

## 🛠 Tech Stack

| Tech         | Description                              |
|--------------|------------------------------------------|
| **Next.js**  | React-based framework for fast rendering |
| **TypeScript** | Strong typing and safer code             |
| **Tailwind CSS** | Utility-first styling with full control |
| **Framer Motion** | Powerful animations for modern UIs     |
| **Recharts** | Declarative charting for React           |
